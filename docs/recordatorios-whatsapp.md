# Recordatorios gratuitos por WhatsApp

En Gestión de Citas, seleccione la fecha y pulse **WhatsApp** junto a una cita futura. SISS prepara un mensaje con fecha, hora y establecimiento, sin diagnóstico ni DNI. Los números hondureños de 8 dígitos usan +504; para otros países registre el código internacional.

Revise el número y la autorización del paciente, luego abra WhatsApp y envíe el mensaje desde la cuenta del centro. Se necesita WhatsApp o WhatsApp Web con una sesión iniciada e internet. No requiere claves de API, suscripciones ni un proveedor de pago; aplican los costos habituales de conectividad.

Cuando el paciente responda que asistirá, pulse **Registrar confirmación**. Esta acción requiere el permiso `citas:editar` y guarda el estado CONFIRMADA. Abrir el enlace no registra un envío ni una entrega. Si solicita cancelar, use Cancelar; si solicita reprogramar, gestione una nueva fecha con el flujo de citas existente.

El envío y el registro de respuestas son manuales. No hay programación automática a 48/24 horas, sincronización con WhatsApp, comprobantes de entrega ni registro histórico de mensajes. Para dar seguimiento, seleccione diariamente las fechas de mañana y pasado mañana y revise las citas PROGRAMADA.

No se requieren migraciones de base de datos. Reinicie el backend y publique la compilación actualizada del frontend con el procedimiento habitual del entorno.
